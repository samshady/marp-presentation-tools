# MLU Halle-Wittenberg Brand Palette

| Role | Hex | Usage |
|---|---|---|
| Primary Green | `#9FBF47` | h1, blockquote border, accent elements |
| Accent Blue | `#295A97` | h2, strong, table header bg (white text) |
| Grey | `#928781` | header, footer, .focus-text, muted elements |
| Dark Text | `#282828` | Body text, blockquote text |
| Light Bg | `#F5F5F2` | Blockquote bg, persona card bg |
| White | `#FFFFFF` | Section bg, table cell bg |
